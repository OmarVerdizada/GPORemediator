# GPO Remediator 3.3.1

The default Recipes catalog displays every matching control in numeric order, grouped by section, with descriptions, expandable full explanations, recommended states, favorites and control shortcuts. Hierarchy and compact List views remain available.

Each recipe separates automation support from its last recorded implementation result. Controls with no operation are Not assessed; rolled-back, active, verified, review-needed and pending operations retain distinct labels. Recorded results include their time and GPO context and are not presented as a current domain compliance audit.

Dashboard coverage includes total controls, automation-ready mappings, manual controls and unassessed controls. Disconnected change forms show the control recommendation and preparation steps before the domain connection prompt, without fabricating inventory or permitting offline writes.

Validation covers offline rendering and status cases, numeric sorting, escaping, filtering, view switching, mobile layout, JavaScript syntax, portable build and production package synchronization.
