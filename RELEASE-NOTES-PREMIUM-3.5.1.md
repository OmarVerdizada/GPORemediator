# GPO Remediator 3.5.1

The workspace uses neutral graphite surfaces, restrained cool-blue accents, fine borders and a compact dashboard header. Light, dark and system modes remain available; blue, cyan and violet accents and comfortable/compact density are selectable in the appearance menu. Preferences survive navigation and tab reloads in the existing session storage. Large text, high contrast and reduced motion remain supported.

Unmodified Geist Sans and Geist Mono variable WOFF2 fonts ship locally with their SIL Open Font License and pinned upstream source revision. Runtime needs no font CDN or internet access. Technical values use monospaced type; metric and date values use tabular numbers.

The dashboard control map has 405 individually labelled cells grouped into the 19 imported domains. Cells navigate to their controls and distinguish unassessed, recorded-but-unconfirmed, verified, review and rolled-back results. No domain compliance score is inferred. Empty imported sections remain explicitly empty. GPO GUID, plan scope DN and audit hash values have keyboard-accessible copy controls and success/failure notices. Empty GPO search and operations views use local SVG line illustrations.

Authentication, approval and policy mutation endpoints are unchanged. UI checks use an isolated localhost fixture without real-domain writes. Validation covers map counts and status semantics, escaping and copy values, theme/density persistence, preview navigation, mobile layouts, session recovery, local font assets and production package synchronization.
