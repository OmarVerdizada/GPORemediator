# GPO Remediator 3.18.6

Light and Dark share one semantic palette across sign-in, the workspace, policy plans, dialogs and evidence views. Selected cards, status badges, form controls and action buttons use foregrounds that contrast with their surfaces. Printed reports use the light palette.

Select Light, Dark or System from the sign-in screen or the workspace Appearance menu. The browser remembers the choice across tabs and restarts. System follows the operating system. Theme changes update the current page without replacing the form or its draft.

Browser regression coverage includes desktop and mobile layouts, light and dark text contrast, theme persistence in a new tab, theme switching during data entry, and confirmation that appearance changes do not submit policy writes.
