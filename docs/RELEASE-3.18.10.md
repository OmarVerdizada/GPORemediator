# GPO Remediator 3.18.10

Bulk Apply and rollback now retain recorded results when the service stops between saving an individual result and updating the parent workflow. Startup restores the association from durable records. Completed full-GPO rollback receipts also reconcile the affected child rows and clear stale forward evidence. Interrupted workflows still require review.

Older batches remain accessible from their operation and through direct batch lookup. Both routes enforce ownership. Rollback inspection exposes batch membership when the recent-workflow list no longer includes the original Apply. A closed bulk dialog stops its own polling.

Historical Print Spooler configuration evidence is qualified consistently in History, exports and pilot promotion. Settings keeps its keyboard focus boundary when another modal opens and closes. The developer validation command runs the current test scripts, and the full audit includes the visual workspace browser test.

The Windows portable package contains the rebuilt backend and frontend. The audit uses mocked AD and GPMC calls, temporary SYSVOL and backup fixtures, and Chromium with a mock HTTP service.

The manual PowerShell bundle now uses the same ordering and line endings in Windows PowerShell 5.1 and PowerShell 7. The remediation evidence fixture loads the same product module used by the browser.
