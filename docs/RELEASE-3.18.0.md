# GPO Remediator 3.18.0

Benchmark now offers optional **Bulk apply**. Select individual controls or a section group, choose one GPO and OU/domain, and generate a read-only preview for up to 20 controls. Each control retains its requested values, stored-value source, link intent and warnings. Review and explicit APPLY approval are required before the durable server queue writes anything. A larger section is split into selectable groups; completing one group does not automatically approve the next.

Computer and User Configuration may share a batch and a GPO. Each keeps its policy half and verification context. User-session verification/refresh uses the recorded computer OU and optional verification user. Domain account controls use the domain root; account controls aimed at an OU retain their local-computer meaning. Optional refresh resolves PDC, computer and signed-in user contexts separately after all writes succeed. Refresh defaults to off.

Related domain-account settings must be explicitly selected with compatible values. The batch orders approved prerequisites, rechecks live state before each write, and enables a selected lockout threshold after selected duration/window changes. It never infers an unselected setting. Every changed control retains its existing full-GPO backup. A write failure or external drift stops later writes and refresh. The batch is sequential, not an all-or-nothing transaction; completed changes remain inspectable and recoverable.

Operations provides a compact bulk receipt that survives browser reload without replaying writes. Results report each control's GPO outcome separately from measured, unavailable or mismatched endpoints. Batch rollback uses the first changed full-GPO snapshot and the final publication anchor. For selected AD account properties it validates every saved post-value, restores only recorded properties in one AD cmdlet call, and reads them back independently. Restored child records cannot retain stale forward success claims; their details lead back to the batch result. Snapshot restoration still does not certify an endpoint undo when the pre-change effective value was not captured.

The existing single-control form, navigation and deployment model remain. No Workflow center or Password policies page is reintroduced. No credentials, AD policy or Windows configuration are changed by installing this UI feature. Validation details and limitations are recorded in [audit evidence](audit/3.18.0/validation.md).
