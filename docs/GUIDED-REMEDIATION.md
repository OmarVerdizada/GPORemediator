# Four guided controls (3.7.1)

Open Benchmark, search the control ID, and open Overview or Remediation. The guide works without an AD connection. It includes target/OS/management-source checks, read commands, the remediation procedure, verification limits, recovery and official Microsoft links. Copy is a clipboard action only. No backend job, credential delegation, remote execution, policy write or compliance result is created by viewing/copying.

| Control | Supported operator procedure | Policy ownership |
| --- | --- | --- |
| 1.2.3 | Check OS/update support and all lockout values. Export current security settings. In local `secpol.msc`, Account Policies → Account Lockout Policy → Allow Administrator account lockout → Enabled. Preserve the original defined/undefined state and restore only changed values. | Built-in local Administrator policy. A domain or MDM policy must be changed at its authoritative source. The guide does not automatically configure DCs. |
| 2.3.11.6 | Review logon hours/SMB dependencies. Export settings. In local `secpol.msc`, Local Policies → Security Options → Network security: Force logoff when logon hours expire → Enabled. Test SMB behavior in a lab and restore only the changed value if needed. | Local versus domain account policy must be distinguished. Do not use this endpoint procedure on a DC. This affects SMB, not general desktop/RDP sign-out. |
| 18.10.43.10.1 | Use the displayed `Set-MpPreference -OobeEnableRtpAndSigUpdate $true` procedure with JSON backup and guarded restore. Read the property again; behavior requires a clean OOBE test. | Endpoint Defender preferences, unless centrally managed. Setting the property on an already installed machine does not prove prior OOBE behavior. |
| 18.10.43.10.2 | Use the displayed `Set-MpPreference -DisableIOAVProtection $false` procedure with JSON backup and guarded restore. Inspect both preference and Defender health/IOAV state. | Endpoint Defender preferences, unless centrally managed. A configured value does not prove every downloaded file is safe. |

## What executes

The product renders bundled, escaped instructions. The operator executes any copied commands in elevated Windows PowerShell **on the intended endpoint**. Context commands read OS, machine/domain role, caller identity and computer policy information. `secedit /export /mergedpolicy` writes a uniquely named temporary review file but changes no security policy; the exported file is not an automatic whole-machine rollback template. A missing key means unknown, not disabled.

The two Defender apply examples reject DCs, missing parameters, unknown prior values, non-Normal/inactive Defender and enabled Tamper Protection. They save the previous Boolean and endpoint/control identity in a uniquely named JSON file under the operator's LocalAppData before setting a single preference. A post-read must match. Keep the printed path. The restore example requires that exact trusted backup, validates its endpoint/control/types and refuses to overwrite a changed current value. These checks are conservative guardrails, not a complete policy-ownership detector. Inspect GPO/Intune management before use; centrally managed policy can overwrite a local preference. Never disable protection to force the example to work.

These are operator-run examples, not signed executable packages or an endpoint agent. The JSON is not signed and must remain trusted. Windows/Defender support and effective behavior need laboratory validation. Reading/copying a guide or successfully setting a preference does not create a verified product operation. The catalog remains **405 total / 401 automatic GPO mappings / 4 guided controls**. A future endpoint execution feature needs separate approvals, authentication, target allowlists, durable evidence and real-environment tests.

## GPO versus endpoint

A domain GPO is appropriate when the setting must be continuously governed for an OU/domain. Edit that authoritative policy in GPMC and validate resulting endpoint behavior. The product still blocks automatic Apply for these four controls. For a standalone or locally governed endpoint, use the displayed local procedure. Local remediation does not require a GPO selection, GPO backup, replication or `gpupdate /force`; any later domain/MDM policy can supersede it.

The 3.7.1 metadata fixes identify 1.2.3 as a built-in local Administrator control with desired state Enabled, and map 2.3.11.6 to Security Template `System Access / ForceLogoffWhenHourExpire`. `EnableForcedLogOff` belongs to a different related policy. Neither fix enables automatic writes.
