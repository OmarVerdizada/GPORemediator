GPO Remediator - offline/bootstrap notes

1. Normal operation uses the already published self-contained win-x64 runtime and does not require Node.js, npm or pnpm.
2. A rebuild is required only when the packaged runtime is missing/outdated or Repair is requested.
3. A rebuild is a developer/release operation and requires an approved .NET 8 SDK plus the backend's restored NuGet packages. The production launcher never downloads or provisions build tools.
4. Real AD/GPO execution requires Kerberos PowerShell remoting to the configured writable DC. The selected DC must have the ActiveDirectory and GroupPolicy PowerShell modules/GPMC feature. The local management host does not auto-install or require RSAT for the production workflow.
5. The web UI is local-only on http://127.0.0.1:5080 in this release. No HTTPS certificate is required while it remains loopback-only.
6. Use PRODUCTION-TEST-CHECKLIST.md before any production rollout.
