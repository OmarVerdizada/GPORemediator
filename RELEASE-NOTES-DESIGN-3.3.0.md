# GPO Remediator 3.3.0

The dashboard now has a focused policy workspace header, working catalog/guide shortcuts and a current-environment panel showing the discovered domain, GPO and scope counts, readiness and operator role. All values come from the existing session and inventory; unavailable counts remain unavailable.

A shared visual layer improves light/dark palettes, text contrast, card spacing, navigation, catalog statistics, selected filters, rule rows, input fields, refresh choices, change-plan panels, operation cards and confirmation controls. Mobile layouts use stacked environment panels, compact statistics and larger controls. Keyboard focus and reduced-motion support are preserved.

Validation: desktop dashboard and catalog, guide shortcut, target-form submission, rollback refresh dialog, dark theme and mobile overflow checks with an offline browser fixture; JavaScript syntax, session recovery regression, portable build and production package/source synchronization checks. Domain execution behavior remains covered by the 3.2.1 workflow tests. Visual fixture data is not live AD evidence.
