GPO Remediator 3.1.3 - production release integrity

The release contains the real Windows/Active Directory remediation workflow.
Development scenarios, browser harnesses, fixtures, sample account configuration
and debugging symbols are excluded from the production tree/runtime archive.

Release preparation:
- Build-Portable.ps1 builds and packages the self-contained Windows x64 runtime.
- scripts/Validate-ProductionPackage.py validates 405 CIS mappings (401 writable,
  four manual/read-only), source/dist consistency and runtime archive integrity.
- Source/runtime fingerprints and the runtime ZIP SHA-256 protect installation.

Production publication, replication and effective endpoint compliance are live
operation results. Review them using PRODUCTION-OPERATIONS.md.
