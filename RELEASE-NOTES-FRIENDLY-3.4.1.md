# GPO Remediator 3.4.1

A warm neutral background, teal actions, lavender catalog totals and amber manual-review accents replace the blue operator palette. Controls, text and mobile records are easier to read, with consistent rounded surfaces and visible keyboard focus.

The catalog starts with three clear totals and a full-width search field. Advanced level/type/support/status filters use a native disclosure with retained open state; active filters remain visible after rerenders. View selection moves into a compact accessible menu. All four views, section navigation, favorites, pagination and CSV export remain available. Clear filters resets the disclosure and all constraints.

Desktop/mobile, dark theme, filter disclosure and clearing, view switching, favorites, pagination and detail navigation were verified with offline representative fixtures. JavaScript checks, status/filter/session regressions, portable build and production package synchronization were also checked. No live AD changes were performed for visual verification.
